# ShopAssist AI 🤖

An AI-powered FAQ chatbot built using Flask and NLP.

## Features
- NLP-based question matching
- Modern chatbot UI
- Real-time responses
- FAQ system using JSON
- Flask backend

## Technologies Used
- Python
- Flask
- Scikit-learn
- HTML/CSS/JavaScript

## Run Locally

```bash
pip install flask scikit-learn
python app.py
